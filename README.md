# AuraFlow

AuraFlow — приложение для медитации под Android. Практика сопровождается анимацией песка на вибрирующей пластине (фигуры Хладни) и звуком поющей чаши. Графика и звук создаются программно, изображения и аудиофайлы в проекте не используются.

## Возможности

При первом запуске пользователь отвечает на четыре вопроса, и приложение составляет план занятий на 7 дней. Новый день плана открывается по календарю. Практика состоит из этапов с текстовыми подсказками, озвучка подсказок включается в настройках. До и после практики пользователь отмечает настроение, история сессий и график настроения доступны в личном кабинете.

Прогресс отображается в виде персонажа, который растёт по уровням. Сессия, пройденная менее чем на 80 %, засчитывается частично. Также в приложении есть короткая практика при тревоге, конструктор собственных практик, три техники дыхания, фоновые звуки природы и ежедневное напоминание. Цитаты для раздела «Мысль дня» загружаются из этого репозитория, без интернета используется встроенная копия.

## Запуск

Для сборки нужна Android Studio версии 2024.2 или новее, для запуска — устройство или эмулятор с Android 8.0 и выше. Репозиторий клонируется командой `git clone https://github.com/jjuriia/AuraFlow.git`, затем папка проекта открывается в Android Studio, и приложение запускается кнопкой Run.

Сборка из командной строки выполняется командами `./gradlew assembleDebug` (отладочная версия), `./gradlew assembleRelease` (версия с обфускацией) и `./gradlew test` (модульные тесты). В Windows вместо `./gradlew` используется `gradlew.bat`. Готовый APK находится в папке `app/build/outputs/apk/`. Release-версия подписана отладочным ключом, для публикации в магазине приложений нужен собственный ключ.

## Архитектура

Приложение построено по шаблону MVVM. Слой `ui` содержит экраны на Jetpack Compose, их ViewModel, собственные компоненты, тему и навигацию. Слой `domain` содержит логику, не зависящую от Android, и покрыт модульными тестами. Слой `data` отвечает за хранение данных, сеть, звук и напоминания. Зависимости собираются в классе `AppContainer`.

Пароль хранится только на устройстве в виде хеша PBKDF2 с солью. Для release-сборки включены обфускация R8 и удаление неиспользуемых ресурсов, правила находятся в файле `app/proguard-rules.pro`.

## Библиотеки

Kotlin 2.0.21, Kotlin Coroutines 1.9.0, Jetpack Compose (BOM 2024.12.01), Material 3, Navigation Compose 2.8.5, Lifecycle ViewModel 2.8.7, Room 2.6.1, DataStore Preferences 1.1.1, Retrofit 2.11.0 с Gson, WorkManager 2.10.0, Core SplashScreen 1.0.1, JUnit 4.13.2. Версии указаны в файле `gradle/libs.versions.toml`.

## Ограничения

Озвучка работает только при наличии русского голоса в системном синтезаторе речи. На Android 13 и новее для напоминаний требуется разрешение на уведомления. Время напоминания может немного смещаться в режиме экономии заряда.
