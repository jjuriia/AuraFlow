# AuraFlow — медитация на звуке и песке

AuraFlow — Android-приложение для тренировки внимания. Ядро практики — «поющая пластина»:
синтезированный звон чаши заставляет песок собираться в фигуры Хладни, а касание пластины
отмечает момент, когда вы заметили отвлечение и вернули внимание.

Учебный проект по дисциплине «Технологии разработки мобильных приложений»,
БГТУ «ВОЕНМЕХ» им. Д.Ф. Устинова, группа О732Б.

## Возможности

- Онбординг из 4 вопросов (цель, опыт, время, удобная часть дня) и локальная регистрация.
- Личный 7-дневный план, собранный по ответам онбординга.
- Сессия из 5 этапов: настрой → дыхание → объект внимания → сканирование тела → завершение.
- Направляемые фразы на экране и опциональная озвучка (TextToSpeech).
- Синтез звона чаши без аудиофайлов (AudioTrack).
- Отметка настроения до и после сессии, история и статистика.
- Галерея уникальных узоров Хладни — по одному на каждую сессию.
- Дух-хранитель на главном экране, отражающий регулярность практики.
- Ежедневное напоминание (WorkManager).
- «Мысль дня»: 100 цитат на русском загружаются по сети один раз и хранятся локально.

## Технологии

| Назначение | Библиотека |

| Тесты | JUnit 4.13.2, kotlinx-coroutines-test |
| Обфускация | R8 (minify + shrinkResources) |

## Архитектура

```
ui/      — экраны Compose, ViewModel (StateFlow), кастомные компоненты, тема, навигация
domain/  — чистый Kotlin без Android: модели, математика Хладни, план, статистика, хеширование пароля
data/    — Room, DataStore, Retrofit, синтез звука, озвучка, напоминания, репозитории
```

ViewModel получает данные из репозиториев слоя `data` и вычисления из слоя `domain`,
отдаёт экрану неизменяемое состояние через `StateFlow`. Зависимости собираются вручную
в `AppContainer` (без DI-фреймворка).

## Требования

- Android Studio Ladybug (2024.2) или новее.
- JDK 17 (входит в Android Studio).
- Устройство или эмулятор с Android 8.0 (API 26) и выше.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/jjuriia/AuraFlow.git
   ```
2. Откройте папку проекта в Android Studio (**File → Open**) и дождитесь синхронизации Gradle.
3. Подключите телефон с включённой отладкой по USB и нажмите **Run ▶**.

### Сборка из командной строки

```bash
./gradlew assembleDebug      # отладочная сборка
./gradlew assembleRelease    # обфусцированная сборка (R8)
./gradlew test               # юнит-тесты
```

В Windows используйте `gradlew.bat` вместо `./gradlew`.

Готовый APK: `app/build/outputs/apk/release/app-release.apk`. Установка на подключённый телефон:

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

Release-сборка подписана debug-ключом, чтобы её можно было сразу установить.
Для публикации в магазине приложений нужен собственный ключ подписи.

## Примечания

- **Уведомления.** На Android 13+ приложение запрашивает разрешение при включении напоминаний.
- **Озвучка.** Использует системный синтезатор речи. Если русский голос не установлен,
  фразы показываются только текстом.
- **Цитаты.** Если при первом запуске сети нет, приложение берёт ту же коллекцию из `assets`
  и повторяет загрузку при следующем запуске.
