# AuraFlow

Приложение для медитации под Android, которое я делала как учебный проект по «Технологиям разработки мобильных приложений» (БГТУ «ВОЕНМЕХ», группа О732Б).

Мне хотелось, чтобы медитация была не просто таймером с голосом. Поэтому в центре экрана лежит «пластина» с песком: когда звучит поющая чаша, песок собирается в фигуры Хладни, как в настоящем физическом опыте. На вдохе узор рассыпается, на выдохе собирается обратно. Если во время практики отвлеклась на мысли, можно коснуться пластины — так отмечается, что внимание вернулось.

Звук чаши, песок, дух-хранитель и звуки природы нарисованы и синтезированы в коде, никаких картинок и аудиофайлов в проекте нет.

## Что умеет

- В начале четыре вопроса (зачем медитировать, был ли опыт, сколько минут в день, когда удобно), и по ответам строится план на 7 дней. Новый день плана открывается на следующий день по календарю, повторять сегодняшний можно сколько угодно.
- Практика идёт по этапам: настрой, дыхание, объект внимания, сканирование тела, завершение. Фразы-подсказки всегда на экране, озвучку можно включить в настройках.
- Перед практикой и после неё отмечаешь настроение, в личном кабинете потом виден график «до/после».
- После каждой сессии остаётся свой узор, они собираются в галерею.
- На главном экране живёт дух-хранитель. Он растёт по уровням от практик и тускнеет, если долго не заниматься. Если прервать практику раньше 80 %, засчитываются только минуты.
- Вкладка «Практики»: SOS на 3 минуты для момента, когда накрывает тревога (дыхание и заземление «5-4-3-2-1»), короткая пауза на 2 минуты и конструктор, где можно собрать свою практику из блоков.
- Три техники дыхания на выбор (4–6, «квадрат» 4–4–4–4 и 4–7–8) и фоновые звуки: дождь, прибой, ветер. Звук включается и выключается прямо во время практики.
- Напоминание раз в день, причём только если сегодня ещё не занималась.
- «Мысль дня»: 100 цитат загружаются из этого репозитория при первом запуске. Если интернета нет, берутся из копии внутри приложения.

## Как запустить

Нужна Android Studio (Ladybug 2024.2 или новее) и телефон или эмулятор с Android 8.0+.

1. Склонировать репозиторий:
   ```
   git clone https://github.com/jjuriia/AuraFlow.git
   ```
2. Открыть папку в Android Studio через File → Open и подождать, пока Gradle всё скачает.
3. Выбрать телефон (с включённой отладкой по USB) или эмулятор и нажать Run ▶.

Можно и без студии, из терминала в папке проекта (на Windows вместо `./gradlew` пишется `gradlew.bat`):

```
./gradlew assembleDebug     обычная сборка
./gradlew assembleRelease   сборка с обфускацией R8
./gradlew test              юнит-тесты
```

APK появляется в `app/build/outputs/apk/`. Его можно просто скинуть на телефон и установить, Android попросит разрешить установку из неизвестного источника. Release-версию я подписываю отладочным ключом, чтобы она ставилась без лишних настроек. Для Google Play так нельзя, там нужен свой ключ.

## Как устроено

Архитектура MVVM, код разбит на три части:

- `ui` — экраны на Jetpack Compose, их ViewModel, свои компоненты (пластина, чаша, шкала настроения, дух), тема и навигация;
- `domain` — всё, что не зависит от Android: физика песка, синтез звука, план, статистика, проверка полей и хеширование пароля. Эту часть покрывают тесты;
- `data` — база Room, DataStore, загрузка цитат через Retrofit, проигрывание звука, озвучка и напоминания.

Экран получает состояние из ViewModel через `StateFlow`, а ViewModel берёт данные из репозиториев. Зависимости я собираю вручную в `AppContainer`: для проекта такого размера отдельный DI-фреймворк показался лишним.

Пароль хранится только на телефоне и только в виде хеша (PBKDF2 с солью). Для release-сборки включены R8 и удаление неиспользуемых ресурсов, правила лежат в `app/proguard-rules.pro`.

## Что может пойти не так

- Если в системе нет русского голоса для синтеза речи, озвучка не заработает, но фразы всё равно будут на экране.
- На Android 13 и новее при включении напоминаний приложение попросит разрешение на уведомления. Без него напоминания не придут.
- Время напоминания примерное: Android в режиме экономии батареи может немного его сдвинуть.
